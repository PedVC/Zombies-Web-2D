# Zombies Web 2D

Jogo de sobrevivência a zombies, por rondas, executado no navegador com HTML5 Canvas, CSS e JavaScript. Não requer instalação, contas, servidor ou dependências.

## Executar

Abrir `index.html` num navegador moderno. Selecionar o mapa, o modo visual e um ou dois jogadores e começar a jogar.

## Controlos

| Ação | Jogador 1 | Jogador 2 |
|---|---|---|
| Mover | WASD | Setas |
| Apontar | Rato | Automático |
| Disparar | Clique esquerdo | P |
| Recarregar | R | O |
| Interagir | E | E |
| Pausa | ESC ou Espaço | ESC ou Espaço |

## Funcionalidades

- Três mapas: instalação abandonada, ruas em ruínas e laboratório subterrâneo.
- Rondas progressivas, pontuação, munições, melhorias de armas e vantagens.
- Modos de contraste e de acessibilidade cromática.
- Um ou dois jogadores locais.

## Privacidade

O jogo não pede nomes, idades, contactos, contas ou outros dados pessoais. Não usa `localStorage`, cookies, análises nem serviços externos. Os valores de jogo existem apenas em memória durante a sessão.
